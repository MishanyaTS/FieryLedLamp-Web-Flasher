# Общие компоненты сайта

`header/` содержит шаблон шапки, значки, её стили и сценарии.
`page-ui.css` содержит оформление руководств, MQTT, форума, приложений,
регистрации, служебных страниц и Web Flasher.

После изменения общих файлов выполните из корня репозитория:

```sh
python scripts/render-header.py
python scripts/render-header.py --check
```

Сборка обновляет шапки и версии ресурсов в HTML, а также копирует стили
страниц в `website/public/page-ui.css` и `firmware/page-ui.css`.
Правьте исходник в этой папке: копии обновляются автоматически при публикации.
