Подключение и настройка WQTT

Пошагово: получить данные брокера, перенести их в FieryLedLamp и проверить управление.

Открыть WQTT Все команды Умный дом
Подключение 1. Аккаунт WQTT 2. Данные брокера 3. Настройки лампы 4. Топик управления 5. Проверка 6. Команды WQTT

1. Создайте аккаунт WQTT

Зарегистрируйтесь в WQTT и откройте параметры вашего MQTT-брокера.

Перейти в WQTT

2. Скопируйте данные брокера

ServerАдрес сервера
PortОбычный MQTT-порт
UserЛогин
PasswordПароль
Port TLSНе использовать
WebSocketНе использовать
Важно

В FieryLedLamp указывайте обычный MQTT-порт из поля Port, а не TLS или WebSocket.

3. Заполните MQTT в FieryLedLamp

Откройте Web-интерфейс лампы → MQTT и заполните:

MQTTВключить.
Адрес брокераЗначение Server из WQTT.
ПортЗначение Port.
Имя пользователяЗначение User.
ПарольЗначение Password.
Базовый топикНапример Lamp.

Сохраните настройки и перезагрузите лампу. После запуска статус MQTT должен быть «ПОДКЛЮЧЕНО».

4. Топик управления

При базовом топике Lamp команды отправляются сюда:

Топик управления

Lamp/LedLamp_<ID>/cmnd

Точный LedLamp_<ID> смотрите в Web-интерфейсе FieryLedLamp в настройках MQTT.

5. Проверьте управление

Отправьте несколько простых команд в .../cmnd:

P_ONВключить лампу.
P_OFFВыключить лампу.
BRI50Установить яркость 50%.
EFF10Выбрать эффект №10.

Если команды выполняются, подключение WQTT настроено правильно.

6. Как прописывать команды в WQTT

Для обычных переключателей топик управления один и тот же, а команды задаются отдельно. Для ползунков используйте шаблон с {value}.

ПитаниеТопик: .../cmnd
ВКЛ: P_ON · ВЫКЛ: P_OFF
ЦиклТопик: .../cmnd
ВКЛ: FAV_ON · ВЫКЛ: FAV_OFF
ЗвукТопик: .../cmnd
ВКЛ: SO_ON · ВЫКЛ: SO_OFF
ПодсветкаТопик: .../cmnd
ВКЛ: LUMOS_ON · ВЫКЛ: LUMOS_OFF
ЯркостьТопик: .../cmnd
Команда: BRI{value} · диапазон 1–100
СкоростьТопик: .../cmnd
Команда: SPD{value} · диапазон 1–255
МасштабТопик: .../cmnd
Команда: SCA{value} · диапазон 1–100
ЭффектТопик: .../cmnd
Команда: EFF{value} · диапазон 0–133
Пример ползунка

При команде BRI{value} значение 75 превращается в команду BRI75.
