Подключение и настройка WQTT

Пошаговая настройка облачного брокера WQTT для FieryLedLamp: создаём аккаунт, получаем параметры брокера, переносим их в лампу и проверяем управление.

Открыть WQTT Все MQTT-команды
Настройка WQTT 1. Аккаунт 2. Данные брокера 3. FieryLedLamp 4. Топики 5. Проверка 6. Подсветка

1. Создайте аккаунт WQTT

Откройте панель WQTT, зарегистрируйтесь или войдите в существующий аккаунт. После активации брокера в кабинете появятся параметры подключения.

Перейти в панель WQTT

2. Найдите параметры MQTT-брокера

В кабинете WQTT откройте информацию для подключения к брокеру. Для FieryLedLamp нужны следующие значения:

ServerНапример m4.wqtt.ru
PortОбычный MQTT-порт
UserЛогин MQTT
PasswordПароль MQTT
Port TLSНе использовать
WebSocketНе использовать
Выбирайте поле Port

Текущая настройка FieryLedLamp использует обычное MQTT TCP-соединение. Не вводите port_tls и WebSocket-порт.

3. Перенесите данные в FieryLedLamp

Откройте Web-интерфейс лампы → MQTT и заполните поля:

MQTT

Включите MQTT-клиент.

Адрес брокера

Скопируйте значение Server из WQTT, например m4.wqtt.ru.

Порт

Скопируйте обычный Port.

Имя пользователя

Скопируйте User.

Пароль

Скопируйте Password.

Базовый топик

Укажите, например, Lamp.

Сохраните настройки и перезагрузите лампу. После запуска статус MQTT должен перейти в «ПОДКЛЮЧЕНО».

4. Топики FieryLedLamp в WQTT

При базовом топике Lamp лампа формирует:

КомандыLamp/LedLamp_<ID>/cmnd
СостояниеLamp/LedLamp_<ID>/snd
JSONСостояние лампы

Точный LedLamp_<ID> смотрите в Web-интерфейсе лампы в настройках MQTT.

Единое состояние для всех команд

Независимо от того, чем вы управляете — питанием, эффектом, яркостью, звуком, циклом или подсветкой — состояние отслеживается через общий JSON-топик .../snd. Для принудительного обновления отправьте STATE в .../cmnd.

5. Проверьте управление

Опубликуйте сообщение в командный топик .../cmnd:

STATEЗапрос состояния.
P_ONВключить лампу.
P_OFFВыключить лампу.
BRI50Установить яркость 50%.

Подпишитесь на .../snd. После команды STATE должен прийти JSON с текущим состоянием лампы.

6. Настройка «Подсветки» в WQTT

Для управления подсветкой используйте тот же командный топик .../cmnd:

LUMOS_ONВключить подсветку.
LUMOS_OFFВыключить подсветку.

Состояние после управления подсветкой, как и после остальных MQTT-команд, отслеживается через общий JSON-топик .../snd.
