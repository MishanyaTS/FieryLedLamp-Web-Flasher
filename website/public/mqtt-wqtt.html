Подключение и настройка WQTT

Пошаговая настройка облачного брокера WQTT для FieryLedLamp: создаём аккаунт, получаем параметры брокера, переносим их в лампу и проверяем управление.

1. Создайте аккаунт WQTT

Откройте панель WQTT, зарегистрируйтесь или войдите в существующий аккаунт. После активации брокера в кабинете появятся параметры подключения.

Перейти в панель WQTT

2. Найдите параметры MQTT-брокера

В кабинете WQTT откройте информацию для подключения к брокеру. Для FieryLedLamp нужны следующие значения:

ServerНапример m4.wqtt.ru
PortОбычный MQTT-порт
UserЛогин MQTT
PasswordПароль MQTT
Port TLSНе использовать
WebSocketНе использовать
Выбирайте поле Port

Текущая настройка FieryLedLamp использует обычное MQTT TCP-соединение. Не вводите port_tls и WebSocket-порт.

3. Перенесите данные в FieryLedLamp

Откройте Web-интерфейс лампы → MQTT и заполните поля:

MQTT

Включите MQTT-клиент.

Адрес брокера

Скопируйте значение Server из WQTT, например m4.wqtt.ru.

Порт

Скопируйте обычный Port.

Имя пользователя

Скопируйте User.

Пароль

Скопируйте Password.

Базовый топик

Укажите, например, Lamp.

Сохраните настройки и перезагрузите лампу. После запуска статус MQTT должен перейти в «ПОДКЛЮЧЕНО».

4. Топики FieryLedLamp в WQTT

В самой лампе используется обычный MQTT-топик команд и общий JSON-топик состояния. Но в настройках устройства WQTT для поля «Топик состояния» к топику .../snd нужно дописать JSON-путь нужного параметра.

Топик управленияLamp/LedLamp_<ID>/cmnd
Общий JSONLamp/LedLamp_<ID>/snd
Состояние в WQTT.../snd$.поле
Пример для питания

Топик управления: Lamp/LedLamp_<ID>/cmnd
Команда ВКЛ: P_ON
Команда ВЫКЛ: P_OFF
Топик состояния: Lamp/LedLamp_<ID>/snd$.power

То есть топик управления остаётся командным .../cmnd, а WQTT берёт состояние нужной функции из JSON через суффикс $.поле. Точный LedLamp_<ID> смотрите в Web-интерфейсе лампы в настройках MQTT.

5. Проверьте управление

Опубликуйте сообщение в командный топик .../cmnd:

STATEЗапрос состояния.
P_ONВключить лампу.
P_OFFВыключить лампу.
BRI50Установить яркость 50%.

В WQTT состояние для каждого элемента управления задаётся через нужное поле общего JSON. Например: питание — .../snd$.power, яркость — .../snd$.bri, эффект — .../snd$.effect. Для принудительного обновления лампы можно отправить STATE в .../cmnd.

6. Топики управления и состояния в WQTT

Для всех элементов WQTT используется один и тот же командный топик Lamp/LedLamp_<ID>/cmnd. Отличаются команды и поле состояния после $.

ПитаниеУправление: .../cmnd · ВКЛ: P_ON · ВЫКЛ: P_OFF
Состояние: .../snd$.power → ON / OFF
ЦиклУправление: .../cmnd · ВКЛ: FAV_ON · ВЫКЛ: FAV_OFF
Состояние: .../snd$.cycle → ON / OFF
ЗвукУправление: .../cmnd · ВКЛ: SO_ON · ВЫКЛ: SO_OFF
Состояние: .../snd$.sound → ON / OFF
ПодсветкаУправление: .../cmnd · ВКЛ: LUMOS_ON · ВЫКЛ: LUMOS_OFF
Состояние: .../snd$.lumos → ON / OFF
ЭффектУправление: .../cmnd · команда EFF<N>
Состояние: .../snd$.effect
ЯркостьУправление: .../cmnd · команда BRI<1–100>
Состояние: .../snd$.bri
СкоростьУправление: .../cmnd · команда SPD<1–255>
Состояние: .../snd$.spd
МасштабУправление: .../cmnd · команда SCA<1–100>
Состояние: .../snd$.sca
ГромкостьУправление: .../cmnd · команда VOL<1–30>
Состояние: .../snd$.vol
ТаймерУправление: .../cmnd · команда TMR_SET ...
Состояние: .../snd$.tmr
Важно для WQTT

В поле «Топик состояния» указывайте не просто .../snd, а конкретное поле JSON: например .../snd$.power или .../snd$.lumos. WQTT извлекает из общего JSON только нужное значение.
