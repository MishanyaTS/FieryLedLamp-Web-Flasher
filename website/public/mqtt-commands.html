Все MQTT-команды FieryLedLamp

Все команды отправляются в .../cmnd. Ниже — только рабочий формат команды, диапазон и короткое назначение.

Как использовать команды

Отправляйте payload точно как в таблице — регистр букв важен. Число в <...> заменяется нужным значением.

Пример

Топик: Lamp/LedLamp_<ID>/cmnd
Payload: BRI50
Результат: яркость текущего эффекта 50%.

Питание и состояние

P_ONВключить лампу.
P_OFFВыключить лампу.
STATEПринудительно опубликовать текущее состояние в .../snd.

Эффекты

EFF<N>Выбрать эффект по номеру. Нумерация начинается с 0. Пример: EFF10.
EFF_NСледующий эффект.
EFF_PПредыдущий эффект.
BRI<1–100>Яркость текущего эффекта в процентах. Пример: BRI44.
SPD<1–255>Скорость эффекта. Пример: SPD120.
SCA<1–100>Масштаб эффекта. Пример: SCA50.
GBR<1–100>Задать общую яркость для всех эффектов без немедленного сохранения настроек.

Режим «Цикл»

FAV_ONВключить цикл избранных эффектов.
FAV_OFFВыключить цикл.
FAV_GETЗапросить текущие настройки цикла.
FAV_SET ...Передать полную конфигурацию цикла: состояние, интервал, разброс, сохранение и список выбранных эффектов.

Звук

SO_ONВключить озвучивание эффектов.
SO_OFFВыключить озвучивание эффектов.
VOL<1–30>Громкость. Пример: VOL15.

Подсветка

LUMOS_ONВключить «Подсветку».
LUMOS_OFFВыключить «Подсветку».

Случайные настройки

RND_0Вернуть настройки текущего эффекта по умолчанию.
RND_1Применить случайные настройки к текущему эффекту.
RND_ZВернуть настройки по умолчанию всем эффектам.
RND_C1Включить случайный выбор эффектов в цикле.
RND_C0Выключить случайный выбор эффектов в цикле.
RND_ONВключить случайные настройки эффектов в цикле.
RND_OFFВыключить случайные настройки эффектов в цикле.

Бегущая строка

TXT_ТекстПоказать произвольный текст бегущей строкой.
RUN_T<0–99>Периодичность показа в минутах. 0 — не показывать; больше 60 — показывать постоянно.
RUN_C<0–255>Цвет бегущей строки.
RUN_F0Чёрный фон строки.
RUN_F1Цветной фон строки.
RUN_S<0–255>Скорость бегущей строки.

Будильники, рассвет и закат

ALM_SET<1–7> ONВключить будильник выбранного дня недели.
ALM_SET<1–7> OFFВыключить будильник выбранного дня недели.
ALM_SET<1–7> <минуты>Время будильника в минутах от начала суток. ALM_SET1 390 = 06:30.
DAWN<N>Выбрать вариант рассвета перед будильником.
SUN_SET<1–7> ONВключить закат выбранного дня.
SUN_SET<1–7> OFFВыключить закат выбранного дня.
SUN_SET<1–7> <минуты>Время запуска заката в минутах от начала суток.
SUNS<N>Выбрать вариант заката.

Таймер и физическая кнопка

TMR_SET 1 3 300Установить таймер. Последнее число — время до срабатывания в секундах.
SLEEP1Первый предустановленный таймер сна.
SLEEP2Второй предустановленный таймер сна.
BTN_ONРазблокировать физическую кнопку лампы.
BTN_OFFЗаблокировать физическую кнопку лампы.

Сервисные команды

GETЗапросить состояние в протокольном формате приложения. Для обычной MQTT-автоматизации удобнее использовать STATE.
RESET_ALLСбросить настройки лампы к значениям по умолчанию. Используйте только если это действительно нужно.
Состояние команд

После управления читайте актуальное состояние из .../snd. В WQTT для конкретного параметра используйте JSON-путь, например .../snd$.power или .../snd$.bri.
