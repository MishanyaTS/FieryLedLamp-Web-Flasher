Как работает MQTT в FieryLedLamp

Лампа сама подключается к MQTT-брокеру по Wi-Fi. Управляющее устройство публикует команду в командный топик, лампа выполняет её и отправляет актуальное состояние в JSON.

1Команда.../cmnd
2FieryLedLampвыполняет команду
3Состояние.../snd
Главное

Отдельные топики для включения, яркости, эффектов и других функций не создаются. Команды идут через один .../cmnd, а состояние — через один .../snd.

1. Получите данные MQTT-брокера

Можно использовать локальный Mosquitto или внешний сервис. Для подключения лампе нужны четыре основных параметра:

Server / HostIP или имя сервера
PortMQTT TCP-порт
UserЛогин MQTT
PasswordПароль MQTT
Base topicНапример Lamp
ProtocolОбычный MQTT TCP
Не путайте порты

Нужен обычный MQTT TCP-порт. HTTPS, WebSocket и TLS-порт не подходят, если отдельно не настроена соответствующая поддержка в прошивке.

2. Заполните MQTT в Web-интерфейсе лампы

Откройте Web-интерфейс FieryLedLamp → настройки MQTT и заполните поля:

MQTTВключить.
Адрес брокераIP или hostname без http:// и https://.
ПортПорт MQTT TCP из настроек брокера.
Имя пользователяЛогин брокера.
ПарольПароль брокера.
Базовый топикНапример Lamp.
Период публикации0 — отправлять состояние при событиях; 1–60 — дополнительно публиковать через указанное число секунд.

Сохраните настройки и перезагрузите лампу. После запуска статус MQTT должен стать «ПОДКЛЮЧЕНО».

3. Топики FieryLedLamp

Полный путь строится из базового топика и уникального ID лампы. Если базовый топик — Lamp:

КомандыLamp/LedLamp_<ID>/cmndСюда отправляются команды.
Состояние JSONLamp/LedLamp_<ID>/sndОтсюда читается состояние.
Старый форматLamp/LedLamp_<ID>/stateLegacy-топик; в текущей сборке может быть отключён.

Точный LedLamp_<ID> лампа формирует автоматически. Используйте топики, показанные в её Web-интерфейсе.

4. Состояние лампы

Основное состояние публикуется в .../snd как JSON. В нём используются поля вроде:

powerON / OFF
cycleON / OFF
effectномер эффекта
briяркость
spdскорость
scaмасштаб
soundON / OFF
volгромкость
tmrтаймер, секунды
lumosON / OFF
Принудительное обновление

Отправьте STATE в .../cmnd, чтобы лампа повторно опубликовала актуальное состояние.

5. Быстрая проверка подключения

Подпишитесь на .../snd и отправьте в .../cmnd по очереди:

STATEДолжен прийти JSON состояния.
P_ONЛампа включается, power становится ON.
P_OFFЛампа выключается, power становится OFF.
BRI50Яркость текущего эффекта устанавливается на 50%.

6. Все команды управления

Полный список вынесен на отдельную страницу, чтобы инструкция подключения оставалась удобной. Команды сгруппированы по питанию, эффектам, циклу, звуку, подсветке, бегущей строке, будильникам, таймерам и сервисным функциям.

7. Если используете WQTT

В WQTT топик управления остаётся .../cmnd, а для отображения состояния конкретного элемента используется JSON-путь, например .../snd$.power, .../snd$.bri или .../snd$.lumos.

8. Подключение к Умному дому

Через WQTT FieryLedLamp можно добавить в Умный дом как несколько отдельных устройств: основная лампа, Подсветка, Цикл и Звук. Для каждого устройства используются свои команды и поле состояния.

Если MQTT не подключается

1.Проверьте, что лампа подключена к Wi-Fi и имеет доступ к брокеру.
2.Сверьте Server, Port, User и Password без лишних пробелов.
3.Не добавляйте http:// или https:// к адресу.
4.После изменения параметров сохраните настройки и перезагрузите лампу.
5.Проверьте точные топики, которые показывает Web-интерфейс лампы.
