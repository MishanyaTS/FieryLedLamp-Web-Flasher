Подключение брокера

Пошаговая настройка MQTT для FieryLedLamp: создайте брокер, перенесите параметры в Web-интерфейс лампы, сохраните настройки и проверьте обмен командами.

На странице Что понадобится 1. Создайте брокер 2. Настройте лампу 3. Топики MQTT 4. Команды управления 5. Настройка WQTT 6. Проверка Если не подключается

Что понадобится

Лампа должна быть подключена к домашней Wi-Fi сети и иметь доступ к MQTT-брокеру. Можно использовать брокер в локальной сети или внешний MQTT-сервис.

АдресIP или имя сервера
ПортПорт MQTT TCP
ДоступЛогин и пароль
Важно

Используйте именно адрес MQTT-сервера и его MQTT-порт. Не указывайте адрес Web-панели, HTTPS-порт или WebSocket-порт.

1. Создайте MQTT-брокер

Если у вас уже есть брокер, этот шаг можно пропустить. Для внешнего подключения можно использовать любой сервис, который выдаёт обычный MQTT TCP endpoint. Например, WQTT или собственный Mosquitto.

В личном кабинете брокера создайте сервер или пользователя и сохраните четыре параметра:

HostНапример m4.wqtt.ru
PortПорт из кабинета
UserИмя пользователя
PasswordПароль MQTT
ProtocolMQTT TCP
TopicНапример Lamp
Не копируйте чужой порт

Порт зависит от конкретного брокера. Введите тот номер, который указан именно в настройках вашего MQTT-сервера.

2. Введите параметры в FieryLedLamp

Откройте Web-интерфейс лампы и перейдите в настройки MQTT. Заполните поля данными из кабинета брокера.

Включить MQTT

Включите MQTT-клиент лампы.

Адрес брокера

Введите IP-адрес или доменное имя, например m4.wqtt.ru. Префикс mqtt:// не нужен.

Порт

Введите MQTT TCP-порт, выданный брокером.

Имя пользователя

Введите MQTT-логин. Если ваш локальный брокер разрешает анонимный доступ, поле может быть пустым.

Пароль

Введите пароль MQTT-пользователя.

Базовый топик

Например Lamp. От него лампа автоматически построит полные топики.

Период публикации

0 — публиковать состояние при событиях. Значения 1–60 задают периодическую публикацию в секундах.

Нажмите сохранение настроек, затем перезагрузите лампу. После перезапуска новые адрес, порт, логин и пароль будут использованы для подключения.

3. Какие топики использует лампа

FieryLedLamp автоматически добавляет к базовому топику идентификатор устройства вида LedLamp_<ID>. Отдельный MQTT-топик на каждую функцию не создаётся — все команды управления отправляются как payload в один командный топик.

Если базовый топик — Lamp

Команды: Lamp/LedLamp_<ID>/cmnd
Состояние JSON: Lamp/LedLamp_<ID>/snd

Команды.../cmnd
Состояние JSON.../snd
Legacy state.../state

Топик .../state относится к старому текстовому формату и может быть отключён в текущей сборке. Для автоматизации используйте JSON-топик .../snd.

Полный идентификатор формируется самой лампой. В Web-интерфейсе MQTT отображаются топики подписки и публикации, поэтому вручную вычислять ID не требуется.

4. Все MQTT-команды управления

Все команды ниже отправляются в .../cmnd. Регистр букв важен. Число в угловых скобках заменяется нужным значением.

Питание и состояние

P_ONВключить лампу.
P_OFFВыключить лампу.
STATEЗапросить текущее состояние. Ответ приходит в .../snd.

Эффекты

EFF<N>Выбрать эффект по номеру, например EFF10.
EFF_NСледующий эффект.
EFF_PПредыдущий эффект.
BRI<1–100>Яркость текущего эффекта, например BRI44.
GBR<1–100>Установить общую яркость для всех эффектов без немедленного сохранения в EEPROM.
SPD<1–255>Скорость текущего эффекта, например SPD120.
SCA<1–100>Масштаб текущего эффекта, например SCA50.

Режим «Цикл»

FAV_ONВключить цикл избранных эффектов.
FAV_OFFВыключить цикл.
FAV_SET ...Передать полную конфигурацию цикла: состояние, интервал, разброс, сохранение и список выбранных эффектов.
FAV_GETЗапросить текущие настройки цикла.

Звук

SO_ONВключить озвучивание эффектов.
SO_OFFВыключить озвучивание эффектов.
VOL<1–30>Установить громкость, например VOL15.

Подсветка

LUMOS_ONВключить «Подсветку».
LUMOS_OFFВыключить «Подсветку».
Состояние подсветки

В JSON-топике .../snd поле "lumos" содержит "ON" или "OFF". В WQTT для отдельного состояния можно использовать путь .../snd$.lumos.

Случайные настройки и цикл

RND_0Вернуть настройки текущего эффекта по умолчанию.
RND_1Выбрать случайные настройки текущего эффекта.
RND_ZВернуть настройки по умолчанию всем эффектам.
RND_C1Включить случайный выбор эффектов в режиме «Цикл».
RND_C0Выключить случайный выбор эффектов в режиме «Цикл».
RND_ONВключить случайные настройки эффектов в цикле.
RND_OFFВыключить случайные настройки эффектов в цикле.

Бегущая строка

TXT_ТекстПоказать указанный текст бегущей строкой.
RUN_T<0–99>Периодичность вывода в минутах. 0 — не выводить, значения больше 60 — постоянно.
RUN_C<0–255>Цвет бегущей строки.
RUN_F0Чёрный фон бегущей строки.
RUN_F1Цветной фон бегущей строки.
RUN_S<0–255>Скорость бегущей строки.

Будильники, рассвет и закат

ALM_SET<1–7> ONВключить будильник для выбранного дня недели.
ALM_SET<1–7> OFFВыключить будильник для выбранного дня недели.
ALM_SET<1–7> <минуты>Установить время будильника в минутах от начала суток. Например ALM_SET1 390 = 06:30.
DAWN<N>Выбрать вариант рассвета перед будильником.
SUN_SET<1–7> ONВключить закат для выбранного дня.
SUN_SET<1–7> OFFВыключить закат для выбранного дня.
SUN_SET<1–7> <минуты>Установить время заката в минутах от начала суток.
SUNS<N>Выбрать вариант заката.

Таймер и кнопка

TMR_SET 1 3 300Установить таймер. Последнее значение — время до срабатывания в секундах.
SLEEP1Запустить первый предустановленный таймер сна.
SLEEP2Запустить второй предустановленный таймер сна.
BTN_ONРазблокировать физическую кнопку лампы.
BTN_OFFЗаблокировать физическую кнопку лампы.

Сервисная команда

RESET_ALLПолный сброс настроек лампы к значениям по умолчанию. Используйте осторожно.

6. Проверьте подключение

После перезагрузки откройте статус MQTT в Web-интерфейсе лампы. При успешном соединении должен отображаться статус «ПОДКЛЮЧЕНО».

Для проверки откройте MQTT-клиент, подпишитесь на топик .../snd и отправьте одну из команд в .../cmnd:

STATEЗапросить состояние
P_ONВключить лампу
P_OFFВыключить лампу

После команды STATE лампа должна опубликовать JSON со своим состоянием. В нём могут быть питание, текущий эффект, яркость, скорость, масштаб, звук, таймер и другие параметры.

Если MQTT не подключается

Проверьте параметры по порядку: доступ лампы к Wi-Fi, адрес брокера, MQTT-порт, логин и пароль, а затем базовый топик. После изменения адреса, порта или учётных данных обязательно сохраните настройки и перезагрузите лампу.

Частая ошибка

Не вводите http://, https:// или адрес сайта брокера. Нужны hostname/IP MQTT-сервера и MQTT TCP-порт.

Если внешний сервис предлагает несколько вариантов подключения, выбирайте обычный MQTT TCP endpoint, совместимый с настройками FieryLedLamp.
