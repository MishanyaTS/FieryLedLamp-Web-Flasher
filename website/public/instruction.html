Подробное описание страниц меню FieryLedLamp и назначения основных параметров. Состав пунктов зависит от включённых в прошивке модулей.

01

Главная страница

Основное управление лампой и текущим эффектом.

Включение / выключение

Включает или выключает матрицу. При обычном выключении текущие параметры эффекта сохраняются и затем восстанавливаются.

Выбор эффекта

Позволяет выбрать один из доступных эффектов. Кнопки «Предыдущий» и «Следующий» переключают эффекты по порядку; при включённом режиме избранного могут переключаться только эффекты, отмеченные для цикла.

Яркость

Регулирует яркость текущего эффекта. В актуальной версии шкала эффектов используется в диапазоне 1–100%.

Скорость

Изменяет скорость анимации. Для некоторых эффектов параметр влияет не только на скорость движения, но и на длительность внутренних переходов.

Масштаб / Цвет

Третий параметр эффекта. В зависимости от выбранного эффекта управляет масштабом, плотностью, палитрой, цветом или другим индивидуальным параметром.

По умолчанию

Возвращает настройки только текущего эффекта к значениям из effect.ini. Остальные эффекты не изменяются.

Случайные настройки

Применяет случайные параметры к выбранному эффекту. Случайные значения не должны заменять сохранённые пользовательские настройки эффекта.

Цикл

Быстро включает или выключает автоматическую смену выбранных эффектов. Детальные параметры находятся на странице «Цикл».

Таймер выключения

Запускает выключение лампы через заданное время. Отдельная настройка автоматического отключения может задаваться с шагом 30 минут.

Звук эффекта

При установленном DFPlayer можно включать озвучивание эффектов, менять громкость, папку воспроизведения и эквалайзер.

02

Настройки пользователя

Поведение эффектов, бегущей строки, времени, погоды и пользовательских настроек.

Период вывода времени

Задаёт, как часто время автоматически появляется бегущей строкой на матрице. Значение 0 обычно используется для отключения периодического показа.

Период вывода погоды

Задаёт период автоматического вывода температуры и погодной информации бегущей строкой.

Время на выключенной лампе

Разрешает показывать время, даже когда эффекты и основная матрица выключены.

Погода на выключенной лампе

Разрешает выводить погоду бегущей строкой при выключенной лампе.

Описание погоды

Добавляет после температуры текстовое описание состояния погоды. При отключении температуры описание также не выводится.

Пользовательский текст

Текст, который можно вывести бегущей строкой. Поддерживается вывод поверх текущего эффекта.

Бегущая строка поверх эффектов

Если включено, текст отображается поверх активного эффекта; отдельно задаются скорость, цвет и фон текста.

Скорость и цвет текста

Настраивают скорость движения и цвет символов бегущей строки.

Цветной / чёрный фон текста

Определяет, сохраняется ли изображение эффекта между буквами или фон области текста делается чёрным.

Дневное и ночное время

Задаются часы начала дневного и ночного режима. Они используются для отдельной яркости бегущей строки, дисплея и озвучивания.

Дневная / ночная яркость

Яркость времени и погоды в дневном и ночном режиме. В актуальных версиях задаётся в процентах.

Автояркость ночью

Автоматически уменьшает яркость активных эффектов ночью. Степень уменьшения выбирается в настройках.

Только выбранные эффекты кнопкой

При включении физическая кнопка переключает только эффекты, отмеченные на странице «Цикл».

Случайные параметры в цикле

При смене эффектов в режиме «Цикл» используются случайные параметры без перезаписи сохранённых настроек.

Не включать эффект после питания

Управляет восстановлением работы эффектов после выключения/включения питания.

Автовыключение

Позволяет задать автоматическое выключение через фиксированный интервал. Значение 0 отключает обычное автоотключение.

Сброс настроек эффектов

Восстанавливает параметры всех эффектов из effect.ini. Не путать с кнопкой «По умолчанию» на главной, которая сбрасывает только текущий эффект.

Сохранить настройки эффектов в файл

Сохраняет параметры всех эффектов одновременно в effect.ini и EEPROM.

Сохранение настроек лампы

Создаёт ZIP-архив конфигурации. Такой архив можно использовать для восстановления после изменений или обновления.

03

Начальная настройка

Сеть, имя лампы, время, погода и внешние сервисы.

Имя лампы

Имя SSDP/устройства в локальной сети. Полезно, если используется несколько ламп.

SSID и пароль точки доступа

Имя и пароль собственной Wi-Fi сети лампы. Стандартный пароль 12341234 рекомендуется заменить.

Домашняя Wi-Fi сеть

Основные SSID и пароль роутера. После сохранения лампа подключается к домашней сети.

Дополнительные Wi-Fi сети

Поддерживается несколько сохранённых сетей. При включённом WiFiMulti лампа может подключаться к доступной сохранённой сети.

Режим ESP

Переключает работу между режимом подключения к роутеру и режимом собственной точки доступа.

Часовой пояс

Смещение локального времени относительно GMT/UTC.

Летнее время

Включает дополнительное сезонное смещение времени.

NTP-сервер

Адрес сервера синхронизации времени. Используется при наличии доступа к сети.

Синхронизация с браузером

Позволяет вручную передать лампе текущее время устройства, с которого открыт Web-интерфейс.

Источник погоды

Выбор поддерживаемого погодного сервиса. Для OpenWeather требуется API-ключ.

Город

Можно выбрать город из списка или ввести название на русском и выполнить поиск. Изменения применяются без обязательной перезагрузки.

OpenWeather API Key

Персональный API-ключ OpenWeather. Нужен только при выборе этого источника погоды.

Blynk

При включённой поддержке можно указать токен и разрешить/запретить подключение к Blynk.

Перезагрузка

Перезапускает контроллер для применения параметров, которым требуется полный рестарт.

Сброс всех настроек

Возвращает конфигурационные файлы к заводским значениям и перезагружает лампу. Перед использованием рекомендуется сделать резервную копию.

04

Статический IP

Фиксированные сетевые параметры вместо адреса, полученного от DHCP.

Использовать статический IP

Включает ручную сетевую конфигурацию. Если выключено, адрес назначает роутер по DHCP.

IP-адрес

Постоянный адрес лампы в вашей локальной сети. Он должен находиться в той же подсети, что и роутер, и не конфликтовать с другими устройствами.

Шлюз

Обычно IP-адрес домашнего роутера.

Маска подсети

Для большинства домашних сетей используется 255.255.255.0.

DNS-сервер

DNS, который лампа использует для разрешения имён NTP, MQTT, погодных и других интернет-сервисов.

05

Будильник «Рассвет»

Плавное увеличение яркости к заданному времени отдельно для каждого дня недели.

Дни недели

Для каждого дня отдельно включается будильник и задаются часы и минуты запуска.

Продолжительность рассвета

Определяет длительность плавного набора яркости до установленного времени.

Время после рассвета

Задаёт период, в течение которого режим рассвета остаётся активным после достижения установленного времени.

Максимальная яркость

Конечная яркость режима «Рассвет». В актуальной версии используется диапазон 1–100%.

Звук будильника

Включает звуковое сопровождение через DFPlayer.

Громкость

Отдельная громкость для режима рассвета.

Папка будильника

Выбор папки DFPlayer, из которой воспроизводятся файлы во время будильника.

Озвучивание времени / погоды

Отдельно разрешается произносить время и температуру во время режима рассвета, если соответствующие аудиофайлы присутствуют.

06

Закат

Обратный сценарий рассвета — плавное снижение яркости к заданному времени.

Дни недели и время

Для каждого дня можно отдельно включить режим и задать время запуска.

Продолжительность

Определяет длительность плавного уменьшения яркости.

Яркость

Уровень яркости, от которого начинается сценарий заката.

Звуковое сопровождение

При наличии DFPlayer можно включить звук, выбрать отдельную громкость и папку воспроизведения.

07

Цикл

Автоматическое переключение заранее выбранных эффектов.

Включить цикл

Запускает или останавливает автоматическую смену эффектов.

Выбор эффектов

Галочками отмечаются эффекты, участвующие в цикле. Кнопки «Выбрать все» и «Сбросить выбор» ускоряют настройку списка.

Интервал

Основное время работы одного эффекта перед переключением на следующий.

Дисперсия

Добавляет к интервалу случайное время от 0 до заданного значения, чтобы переключения не происходили строго через одинаковые промежутки.

Случайный порядок

Если включено, выбранные эффекты перемешиваются; если выключено — идут по порядку.

Случайные настройки

При каждом выборе эффекта в цикле могут применяться случайные яркость/скорость/масштаб без сохранения этих случайных значений в EEPROM.

Запускать цикл после включения

Определяет, должен ли режим «Цикл» восстанавливаться после выключения и последующего включения лампы.

08

Настройки звука

DFPlayer Mini, звуковое сопровождение эффектов, времени, погоды, рассвета и заката.

Звук эффектов

Включает или выключает звуковое сопровождение при выборе эффектов.

Громкость эффектов

Общая громкость звуков текущего эффекта.

Папка для каждого эффекта

Каждому эффекту можно назначить номер папки DFPlayer. Для некоторых диапазонов папок прошивка умеет выбирать папку случайно.

Предыдущая / следующая папка

Ручное переключение активной папки воспроизведения.

Эквалайзер

Выбор встроенного режима эквалайзера DFPlayer.

Озвучивание времени днём / ночью

Отдельные переключатели позволяют включать произнесение времени в дневном и ночном режимах.

Озвучивание погоды днём / ночью

Раздельно включается произнесение температуры и описания погоды.

Дневная / ночная громкость

Независимая громкость автоматических голосовых сообщений для дня и ночи.

Тайминги DFPlayer

Параметры длительности произнесения часов, минут, температуры и описания погоды, а также задержка между командами. Используются для подстройки под конкретный DFPlayer и карту памяти.

09

Настройки дисплея

Параметры TM1637 и TFT ST7789.

Время показа часов

Длительность/период отображения часов на внешнем дисплее. Прошивка проверяет допустимый диапазон перед сохранением.

Время показа погоды

Отдельная длительность/период отображения погодной информации.

Показывать погоду на TM1637

Разрешает чередовать погоду с часами на семисегментном дисплее.

Цвет часов TFT

Выбор цвета отображения часов на TFT.

Цвет погоды TFT

Отдельный цвет погодной информации.

Дневная / ночная яркость TFT

Раздельная яркость подсветки/отображения TFT для дневного и ночного периода.

Бегущая строка TFT

Включение собственного текста на TFT независимо от бегущей строки LED-матрицы.

Цвет строки TFT

Выбор цвета текста бегущей строки.

Скорость строки TFT

Регулировка скорости прокрутки текста.

Период строки TFT

Через какой интервал повторно выводить заданный текст.

Текст TFT

Строка, которая будет автоматически прокручиваться по дисплею.

10

Настройки оборудования

Физические модули, матрица, питание и назначение кнопки.

MP3 / TM1637 / TFT / ИК / RTC

Отдельные переключатели включают или выключают работу подключённых модулей. Отключайте отсутствующее оборудование, чтобы прошивка не пыталась его использовать.

Кнопка

Можно полностью отключить физическую кнопку и выбрать её тип: механическая или сенсорная.

Действия по количеству нажатий

Настраиваются номера кликов для включения, следующего/предыдущего эффекта, дополнительного действия, показа IP, времени, смены режима ESP, звука и погоды.

Лимит тока

Ограничивает максимальное потребление матрицы для большинства эффектов.

Лимит тока «Белый свет»

Отдельное ограничение для эффекта с максимальной одновременной нагрузкой на все цветовые каналы.

Тип матрицы

Выбор схемы физического соединения светодиодов.

Ориентация

Определяет направление и поворот координат относительно физически подключённой матрицы.

Порядок цветов

Исправляет порядок каналов RGB/GRB и другие варианты, если цвета на вашей ленте отображаются неверно.

Размер одной матрицы

Ширина и высота одного физического модуля.

Количество матриц

Задаёт число последовательно соединённых модулей по ширине и высоте. Общий размер рассчитывается автоматически.

1 / 2 DATA-линии

Для больших панелей можно выбрать две линии данных. В текущей версии первая линия обслуживает до 2048 LED, остальные светодиоды подключаются ко второй DATA-линии.

Переворот панели

Разворачивает всю собранную панель целиком без физического изменения соединений.

После изменения геометрии

Размеры, число сегментов и количество DATA-линий могут потребовать автоматической перезагрузки лампы. Неверные значения могут привести к неправильному выводу эффектов.

11

Настройки ИК-пульта

Обучение команд пульта без редактирования прошивки.

Обучить команду

Выберите действие, запустите обучение и нажмите нужную кнопку пульта. Принятый код сохраняется автоматически.

Ручной ввод кода

ИК-код можно прописать вручную в десятичном формате DEC.

Комментарии

Для каждой команды можно сохранить собственную подпись, например название кнопки пульта.

Доступные действия

Вкл/выкл, Mute, предыдущий/следующий эффект, цикл, эквалайзер, время, погода, громкость ±, IP, яркость ±, скорость ±, масштаб ±, добавить/удалить избранное, случайные/заводские параметры, папка ± и цифры 0–9 для выбора эффекта.

Автоповтор

Для команд, где это уместно, удержание кнопки пульта может повторять действие.

12

MQTT

Интеграция лампы с брокером MQTT и системами автоматизации.

Включить MQTT

Разрешает подключение MQTT-клиента. Функция работает, когда поддержка MQTT включена при сборке прошивки.

Адрес брокера

Можно указать IP-адрес или DNS-имя сервера, например локальный адрес Home Assistant/Mosquitto или внешний брокер.

Порт

TCP-порт MQTT-брокера.

Пользователь и пароль

Учётные данные для брокера, если авторизация включена.

Базовая часть топика

Используется при формировании топиков подписки и публикации. Web-интерфейс показывает итоговые топики.

Период публикации

0–60 секунд. При значении 0 состояние публикуется только при событии/изменении; значение больше 0 включает периодические публикации.

13

Управление несколькими лампами

Передача основных действий на другие лампы в одной сети.

Лампы 1–5

Можно настроить до пяти удалённых устройств: включить синхронизацию, указать IP/host и добавить понятный комментарий.

Синхронизация состояния

На активные удалённые лампы передаются основные параметры: питание, эффект, яркость, скорость, масштаб и другие поддерживаемые команды.

Синхронизация звука

При наличии MP3 можно синхронизировать выбранную папку озвучивания, а дополнительной настройкой — состояние звука и громкость эффектов.

Сеть

Все лампы должны быть доступны друг другу по указанным адресам. Для стабильной работы удобно использовать статические IP или резервирование DHCP.

14

Подсветка

Отдельная адресная подсветка корпуса, если этот раздел присутствует в вашей сборке.

Включение

Включает и выключает подсветку независимо от основной LED-матрицы.

Количество LED

Количество адресных светодиодов в отдельной подсветке.

Яркость

Независимая яркость подсветки.

Цвет

Ручной выбор цвета через палитру.

Плавное мигание

Периодически плавно увеличивает и уменьшает яркость выбранного цвета.

Плавная смена цвета

Автоматически изменяет оттенок подсветки.

Скорость
