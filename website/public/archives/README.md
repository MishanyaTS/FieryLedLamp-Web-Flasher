# Архивы озвучки для Fiery Led Lamp

Папка рядом с `website/public/images/` (в ней находится схема подключения).

При публикации на HostiMan разместите в `/archives/` два файла:
- `time.zip` — 86 MP3-файлов озвучки времени (в ZIP папка `time/`).
- `weather.zip` — 143 MP3-файла озвучки погоды (в ZIP папка `weather/`).

Архивы подготовлены из ADVERT.zip по нумерации треков: 0000–0160 время; 0200–0351 погода. Папки внутри архивов предназначены для MicroSD + MAX98357A. Прежний DFPlayer Mini использует общую папку ADVERT.

Звуковые ZIP-файлы размещаются на FTP вручную, не сохраняются в Git; workflow публикации исключает `archives/*.zip` из удаления. Ссылки в `instruction.html` включатся после появления ZIP на сервере.
