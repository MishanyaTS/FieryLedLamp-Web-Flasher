# Архивы озвучки для Fiery Led Lamp

Папка рядом с `website/public/images/` (в ней находится схема подключения).

В репозитории находятся два архива, которые автоматически загружаются на HostiMan в `/archives/`:
- `time.zip` — 86 MP3-файлов озвучки времени (в корне ZIP без вложенной папки).
- `weather.zip` — 143 MP3-файла озвучки погоды (в корне ZIP без вложенной папки).

Архивы подготовлены из ADVERT.zip по нумерации треков: 0000–0160 время; 0200–0351 погода. Папки внутри архивов предназначены для MicroSD + MAX98357A. Прежний DFPlayer Mini использует общую папку ADVERT.

ZIP-файлы хранятся в Git вместе с сайтом и публикуются на HostiMan автоматически через `deploy-hostiman.yml`. Отдельная загрузка на FTP не требуется. Ссылки в `instruction.html` станут доступны после успешной публикации и HTTP-проверки архива.

После распаковки на MicroSD создайте папки `/time` и `/weather` и разместите файлы соответствующих архивов внутри этих папок.
