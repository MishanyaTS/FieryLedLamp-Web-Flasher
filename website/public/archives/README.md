# Архивы озвучки для Fiery Led Lamp

Папка рядом с `website/public/images/` (в ней находится схема подключения).

Архивы для озвучивания через усилитель MAX98357A:
- `time.zip` — 86 MP3-файлов озвучки времени (в корне ZIP без вложенной папки).
- `weather.zip` — 143 MP3-файла озвучки погоды (в корне ZIP без вложенной папки).

ZIP-файлы публикуются вместе с основным сайтом при ручном запуске `deploy-hostiman.yml`. На странице инструкции кнопки скачивания появляются после проверки доступности архивов.

Создайте на microSD папки `/time` и `/weather`. Распакуйте файлы `time.zip` в первую папку, `weather.zip` — во вторую.
