# Общая шапка Fiery Led Lamp

Единый источник шапки основного сайта и Web Flasher находится в `website/shared/header/`:

- `template.html` — логотип, поиск, кнопки аккаунта и все пункты меню.
- `header.css` — общий стиль; высота закрытой шапки 90 px при любой ширине экрана.
- `header.js` — поиск, мобильное меню, выпадающие ссылки и отображение аккаунта.
- `icons.svg` — простые контурные значки с оранжевым градиентом.

После правки этих файлов запустите из корня репозитория:

```bash
python3 scripts/render-header.py
python3 scripts/render-header.py --check
```

Сборка также автоматически выполняется в обоих workflow публикации и при подготовке архивов. Правка `website/shared/header/**` или `scripts/render-header.py` запускает публикацию обоих сайтов. Копии шапки между `SHARED_HEADER:START` и `SHARED_HEADER:END` в HTML, а также `header.css` и `header.js` в публичных папках генерируются автоматически; их не нужно редактировать по отдельности. Скрипт сохраняет остальное содержимое страниц и сам выделяет текущий пункт меню. Новая публичная HTML-страница с `<main>` также получает общую шапку. Документы, выполняющие только перенаправление, пропускаются.

Шаблон содержит подстановки `MAIN_BASE`, `ASSET_BASE`, `AUTH_MODE`, `VERSION`, `SYMBOLS`, `NAV:имя` и `CURRENT:/страница.html`. Генератор задаёт абсолютные ссылки на основной сайт для Web Flasher. Версия CSS и JS вычисляется по содержимому общих исходников, поэтому после изменения шаблона или оформления браузер получает актуальные ресурсы.

SVG-значки встроены в HTML и используют локальные ссылки `#fl-header-*`. Это исключает зависимость значка Web Flasher от кеша отдельного файла спрайта. Прежние внешние спрайты и PNG сохранены как неиспользуемые старые материалы.

Пункт Web Flasher есть в основном ряду на каждом сайте. В меню «Начало работы» остаются только «Первый запуск» и «Подключение оборудования». На сайте прошивки выделяется пункт Web Flasher.

Список поиска — прямой потомок общей шапки; он открывается ниже всей шапки и не перекрывается строкой навигации. Высота ограничена доступным местом в окне, при необходимости есть внутренняя прокрутка. Новая выдача всегда начинается с первого результата; клавиатурный выбор прокручивает только список. Поддерживаются мышь, касание, стрелки, Enter и Escape.

Поиск использует `website/public/header-search.json` с содержимым 11 публичных страниц; сборка копирует индекс в `firmware/header-search.json`. Аккаунты, административные данные и динамические сообщения форума в индекс не включаются. Авторизованный пользователь основного сайта видит имя и ссылку на аккаунт; на Web Flasher кнопки ведут на основной сайт. RU показывает текущий язык.
