# Контурная шапка Fiery Led Lamp

Шапка построена по пользовательскому образцу: тёмный фон с угловыми оранжевыми линиями, огненный логотип, поиск, вход и регистрация, нижний ряд простых контурных значков. Значки нарисованы в SVG, без генерации растровых изображений.

Общие ресурсы: `website/public/header.css`, `website/public/header.js`, `website/public/icons/header-outline.svg`. Их точные копии в `firmware/` обеспечивают ту же шапку для Web Flasher. Все HTML-страницы подключают ресурсы с версией `20261031-compact-header`.

Поиск использует `header-search.json` с содержимым 11 публичных страниц. На сайте прошивки используется собственная копия индекса, результаты ведут на основной сайт. Поддерживаются мышь, клавиши вверх/вниз, Enter и Escape. Индекс не включает аккаунты, административные страницы и динамические сообщения форума.

В меню «Начало работы» сохранены быстрые ссылки на подключение оборудования и Web Flasher. В меню MQTT доступны все команды. Вместо «Поддержки» в основном меню размещена прямая ссылка Web Flasher с контурным значком микроконтроллера. На сайте прошивки активен именно пункт Web Flasher.

RU показывает текущий язык сайта. В шапке основного сайта авторизованный пользователь видит имя и ссылку на аккаунт. На Web Flasher кнопки входа и регистрации ведут на основной сайт.

Компактная версия: на компьютере шапка занимает около 85 px вместо прежних 242 px; значки размером 22 px расположены слева от подписей. На мобильных устройствах поиск занимает отдельную строку, вход и регистрация отображаются компактными значками с доступными подписями, а меню раскрывается по кнопке. В разделе «1. Подготовка» страницы «Начало работы» есть кнопка «Подключение», ведущая на `/hardware.html`.
