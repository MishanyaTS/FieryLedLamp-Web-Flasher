# Контурная шапка Fiery Led Lamp

Шапка построена по пользовательскому образцу: тёмный фон с угловыми оранжевыми линиями, огненный логотип, поиск, вход и регистрация, нижний ряд простых контурных значков. Значки нарисованы в SVG, без генерации растровых изображений.

Общие ресурсы: `website/public/header.css`, `website/public/header.js`, `website/public/icons/header-outline.svg`. Их точные копии в `firmware/` обеспечивают ту же шапку для Web Flasher. Все HTML-страницы подключают ресурсы с версией `20261031-outline-header`.

Поиск использует `header-search.json` с содержимым 11 публичных страниц. На сайте прошивки используется собственная копия индекса, результаты ведут на основной сайт. Поддерживаются мышь, клавиши вверх/вниз, Enter и Escape. Индекс не включает аккаунты, административные страницы и динамические сообщения форума.

В меню «Начало работы» сохранены быстрые ссылки на подключение оборудования и Web Flasher. В меню MQTT доступны все команды. Раздел «Поддержка» ведёт к адресу разработчика и существующей странице помощи проекту.

RU показывает текущий язык сайта. В шапке основного сайта авторизованный пользователь видит имя и ссылку на аккаунт. На Web Flasher кнопки входа и регистрации ведут на основной сайт.
